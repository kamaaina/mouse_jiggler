#+title: README

* Description
A mouse jiggler every 60 seconds to move the mouse 1 pixel back and forth to prevent screen lock

* Build

#+begin_example fish
set -x PICO_SDK_PATH /path/to/pico-sdk
cp $PICO_SDK_PATH/external/pico_sdk_import.cmake .

cmake -B build  # -DPICO_BOARD=waveshare_rp2040_zero  <- setting this in CMakeLists.txt for now
cd build
make
#+end_example

** Installation

Put pico into DFU mode first then copy firmware

#+begin_example fish
cp pico_mouse_jiggler.uf2 /path/to/RPI-RP2/
#+end_example

* Serial

use tio to connect and see output. to exit, ctrl-t q
paru -S tio

#+begin_example fish
tio /dev/ttyACM0
#+end_example
